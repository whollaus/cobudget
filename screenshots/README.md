The READMEs show a gallery immediately after the features. `appinfo/info.xml`
uses the payment overview as the first App Store image. Previews retain the
original proportions and are reduced to at most 600 pixels on the longest edge.

Use a new filename revision whenever images change: the App Store image proxy
caches source URLs. New image URLs become public with the corresponding source
and App Store release.

Screenshots are repository documentation assets and are excluded from
installable app packages.
